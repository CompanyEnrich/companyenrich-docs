The V1 API uses `https://api.companyenrich.com` without a `/v1` path prefix. Every request requires [Bearer authentication](/authentication).

V1 includes company enrichment, search, similar-company discovery, people search, saved company lists, and asynchronous job workflows. Its request formats, response formats, pagination, and credit costs can differ from V2. Use the endpoint's own schema when maintaining a V1 integration.
