## Responses and billing

Each endpoint documents its request and response schemas, credit cost, and error responses. Optional expansions add data and may add credits. Check the endpoint's billing description before choosing expansions.

Company and people searches use cursor pagination. Send the same query with the returned cursor to continue; search cursors expire 24 hours after the first page. Geographic lookup cursors expire after 30 minutes.

## Asynchronous work

V2 includes bulk company enrichment and company and people search exports. Use the [batch endpoints](/api-reference/v2/get-batches) to inspect progress and cancel remaining requests, then download results from the corresponding workflow's results endpoint.

## V1 compatibility

V1 remains documented separately. Saved company lists, list-based exports, and filtering by saved-list IDs remain V1 features; they are not part of V2. See the [V1 reference](/api-reference/v1/overview) for those workflows.
