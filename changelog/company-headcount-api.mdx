**March 25, 2026**

Added Company Headcount API to the platform, enabling historical employee count tracking and department-level workforce analysis for any company. This feature surfaces growth signals, layoff patterns, and hiring trends over time — allowing users to monitor workforce changes, benchmark company size, and build data-driven prospecting workflows around team growth and contraction.
