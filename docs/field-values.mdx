Some fields only ever contain a value from a fixed list. The same values work as search filters, so you can copy a value from this page straight into a request. Values are case-sensitive and appear here exactly as the V2 API returns and accepts them.

For open-ended values, such as industries, technologies, and cities, see [Lookup endpoints](#lookup-endpoints).

## Company values

### Company types

Returned in `type`. Accepted by the company search `type` filter.

| Value           | Meaning       |
| --------------- | ------------- |
| `private`       | Private       |
| `public`        | Public        |
| `self-employed` | Self-employed |
| `self-owned`    | Self-owned    |
| `partnership`   | Partnership   |
| `nonprofit`     | Nonprofit     |
| `educational`   | Educational   |
| `government`    | Government    |

### Employee ranges

### Company expansions

Accepted by the `expand` parameter on company endpoints. Each adds 1 credit per company returned.

| Value          | Adds                                           |
| -------------- | ---------------------------------------------- |
| `financial`    | Stock listing, total funding, and funding rounds |
| `keywords`     | Keywords associated with the company           |
| `naicsCodes`   | NAICS codes                                    |
| `technologies` | Technologies the company uses                  |
| `workforce`    | Headcount by department with 12 months of history |

### Workforce departments

Workforce data groups headcount into the same 14 top-level departments as people data. The spelling depends on where the value appears:

| Department             | `workforce.departmentHeadcount` key | `workforceGrowth` and `workforceSize` filter value | Person `department` value |
| ---------------------- | ----------------------- | ------------------------ | ------------------------ |
| C-suite                | `cSuite`                | `c_suite`                | `c-suite`                |
| Product management     | `productManagement`     | `product_management`     | `product-management`     |
| Engineering and technical | `engineeringTechnical` | `engineering_technical` | `engineering-technical`  |
| Design                 | `design`                | `design`                 | `design`                 |
| Education              | `education`             | `education`              | `education`              |
| Finance                | `finance`               | `finance`                | `finance`                |
| Human resources        | `humanResources`        | `human_resources`        | `human-resources`        |
| Information technology | `informationTechnology` | `information_technology` | `information-technology` |
| Legal                  | `legal`                 | `legal`                  | `legal`                  |
| Marketing              | `marketing`             | `marketing`              | `marketing`              |
| Medical and health     | `medicalHealth`         | `medical_health`         | `medical-health`         |
| Operations             | `operations`            | `operations`             | `operations`             |
| Sales                  | `sales`                 | `sales`                  | `sales`                  |
| Consulting             | `consulting`            | `consulting`             | `consulting`             |

The workforce filters also accept `overall` for total headcount. The `workforceGrowth` filter takes a `period` of `m6` (6 months), `y1` (1 year), or `y2` (2 years).

### Email lookup status

Returned in `status` by the [work email lookup](/api-reference/v2/get-people-personid-email).

| Value         | Meaning                                                     |
| ------------- | ----------------------------------------------------------- |
| `found`       | A work email was found. The response includes `email`.      |
| `not-found`   | No work email was found.                                    |
| `unavailable` | No work email is available for this person.                   |
| `pending`     | The lookup is still running. Retry the request later.       |

| Value       | Certainty |
| ----------- | --------- |
| `very-high` | Very high |
| `high`      | High      |
| `medium`    | Medium    |
| `unknown`   | Unknown   |

## Enrichment and batch values

### Batch enrichment item status

Returned in `status` for each item of a [batch enrichment](/api-reference/v2/post-companies-enrich-batch) response. Only `found` items include a `company` and consume credits.

| Value            | Meaning                                         |
| ---------------- | ----------------------------------------------- |
| `found`          | The company was found and returned.             |
| `not-found`      | No company was found for the domain.            |
| `invalid-domain` | The value is not a valid domain.                |
| `pending`        | The company is not stored yet and is scheduled for background enrichment when eligible. Returned when `waitForEnrichment` is `false`. |

### Batch status

Returned in `status` by the [batch endpoints](/api-reference/v2/get-batches-id) for bulk enrichment and search exports.

| Value        | Meaning                                    |
| ------------ | ------------------------------------------ |
| `pending`    | The batch has not started.                 |
| `running`    | The batch is in progress.                  |
| `completed`  | The batch finished.                        |
| `cancelling` | A cancellation was requested and remaining work is stopping. |
| `cancelled`  | The batch was cancelled.                   |

## Lookup endpoints

These values are open-ended, so the API provides free endpoints to find them:

| Values                | Endpoint                                                                           |
| --------------------- | ---------------------------------------------------------------------------------- |
| Industries and their NAICS codes | [`GET /v2/industries`](/api-reference/v2/get-industries)                |
| Keywords              | [`GET /v2/keywords/autocomplete`](/api-reference/v2/get-keywords-autocomplete)     |
| Technologies          | [`GET /v2/technologies/autocomplete`](/api-reference/v2/get-technologies-autocomplete) |
| Positions and titles  | [`GET /v2/positions/autocomplete`](/api-reference/v2/get-positions-autocomplete)   |
| Regions               | [`GET /v2/geo/regions`](/api-reference/v2/get-geo-regions)                         |
| Countries             | [`POST /v2/geo/countries`](/api-reference/v2/post-geo-countries)                   |
| States                | [`POST /v2/geo/states`](/api-reference/v2/post-geo-states)                         |
| Cities                | [`POST /v2/geo/cities`](/api-reference/v2/post-geo-cities)                         |

The [CLI](/docs/cli) lists the fixed values offline with `companyenrich values`.
