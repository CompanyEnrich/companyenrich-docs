---
title: "Authentication"
description: "Authenticate every request with your CompanyEnrich API token."
---

Get your API token from the [CompanyEnrich dashboard](https://app.companyenrich.com), then send it in the `Authorization` header:

```http
Authorization: Bearer YOUR_API_TOKEN
```

Both API versions use the same authentication method and base URL: `https://api.companyenrich.com`.

## Verify your token

The current-user endpoint returns your account information, credit balance, and capabilities without consuming credits.

```bash
export COMPANYENRICH_API_KEY="YOUR_API_TOKEN"

curl --request GET \
  --url https://api.companyenrich.com/v2/me \
  --header "Authorization: Bearer $COMPANYENRICH_API_KEY"
```

## Use the API playground

On an endpoint page, enter **`Bearer YOUR_API_TOKEN`** in the **Authorization** field, including the `Bearer` prefix. The published OpenAPI specifications define this field as the complete header value.

<Note>
The playground sends real API requests. Successful billable operations consume credits according to the endpoint's description.
</Note>

Keep tokens in server-side environment variables or a secret manager. Do not include them in browser code, public repositories, or shared request examples.

See [credits](/docs/credits) and [rate limits](/docs/rate-limit) before sending requests at scale.
