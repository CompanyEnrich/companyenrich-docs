Three steps take you from an API key to a working request.

<Steps>
  <Step title="Get your API key">
    Create a key at [app.companyenrich.com/access-keys](https://app.companyenrich.com/access-keys), then save it in an environment variable:

    ```bash
    export COMPANYENRICH_API_KEY="paste-your-key-here"
    ```
  </Step>
  <Step title="Send your first request">
    This request checks that your key works and shows your credit balance. It is free.

    <CodeGroup>

    ```bash cURL
    curl https://api.companyenrich.com/v2/me \
      -H "Authorization: Bearer $COMPANYENRICH_API_KEY"
    ```

    ```javascript JavaScript
    // npm install @companyenrich/sdk
    import { CompanyEnrich } from '@companyenrich/sdk';

    const client = new CompanyEnrich(); // reads COMPANYENRICH_API_KEY
    console.log(await client.me());
    ```

    ```python Python
    # pip install companyenrich
    from companyenrich import CompanyEnrich

    client = CompanyEnrich()  # reads COMPANYENRICH_API_KEY
    print(client.me())
    ```

    ```ruby Ruby
    # gem install companyenrich
    require "companyenrich"

    client = CompanyEnrich::Client.new # reads COMPANYENRICH_API_KEY
    p client.me
    ```

    ```php PHP
    <?php
    // composer require companyenrich/sdk
    require 'vendor/autoload.php';

    use CompanyEnrich\Client;

    $client = new Client(); // reads COMPANYENRICH_API_KEY
    print_r($client->me());
    ```

    ```bash CLI
    # npm install -g @companyenrich/cli
    companyenrich me
    ```

    </CodeGroup>

    You get back your account's credits and what your plan allows:

    ```json
    {
      "userId": "8d1f3c52-7b0e-4c1a-9f6d-2e5a4b3c1d90",
      "credits": { "used": 12, "total": 1000 },
      "capabilities": { "previews": true }
    }
    ```

    This example is shortened. A `401` response means the key is missing or wrong.
  </Step>

## Good to know

* **Base URL.** Every request goes to `https://api.companyenrich.com`. V2 paths start with `/v2`.
* **Authentication.** Send your key in the `Authorization` header as `Bearer` followed by the key. See [Authentication](/authentication).
* **Credits.** Most requests cost credits for the data they return. Counting matches and checking your account are free. See [Credits](/docs/credits).
* **Rate limits.** See [Rate limits](/docs/rate-limit) before you send requests at scale.
